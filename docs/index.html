Stripe sync

Connect your Stripe account to pull paid payouts automatically. Create a restricted API key with read-only access to Payouts only (Stripe Dashboard → Developers → API keys → Create restricted key). The key is stored only in this browser and is sent only to api.stripe.com. Never paste your full secret key.

Your data
